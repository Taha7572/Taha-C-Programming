# CodeAlpha C Programming Internship

This repository contains three completed C programming tasks from the CodeAlpha internship brief.

## Task 1 — Basic Calculator
A switch-case calculator supporting addition, subtraction, multiplication and division, including division-by-zero handling.

## Task 2 — Matrix Operations
A modular program using functions and 2D arrays for matrix addition, multiplication and transpose.

## Task 3 — Student Management System
A menu-driven record system using structures and file handling. It supports add, delete, update, search and display operations with persistent storage.

## Technology
- C
- Standard C library
- Structures
- Functions
- 2D arrays
- File handling

## Compile
Each task folder contains its own README with compile and run commands.

The CodeAlpha brief requires completing any 2 or 3 of the 4 available tasks and uploading the source code to GitHub in a repository named using the CodeAlpha_ProjectName format.
